# Reconstructing Individual Patient Data from Published Kaplan–Meier Curves

In rare disease research, publications often provide only Kaplan–Meier (KM) survival curves, while health technology assessments (HTAs) require individual patient data (IPD) to project long-term outcomes and inform decision-making.

When IPD is not available, reconstructing it from KM curves is a critical solution for robust analysis.

This R tool leverages a validated algorithm (Guyot et al., 2021) to reconstruct IPD from KM curves, aligning with methodological guidance recognized by NICE's Decision Support Unit. 

For the full R notebook, view https://davidzhao1015.github.io/reconstruct-ipd-km/
